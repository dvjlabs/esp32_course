    ESP32 <---> Flask

    Comincio subito con le scuse... nella lezione della volta scorsa tutto quello che poteva andare storto è andato storto. Per la legge dei grandi numeri la lezione di oggi sarà mondiale... nel dubbio, mi sono preparato al meglio!!!

    Vogliamo imparare a mettere in comunicazione un server web, basato su Flask, con un ESP32. Elenco gli argomenti da affrontare, cercando di andare più possibile in ordine:

    • Dal PC, realizzare un semplice sito in Flask.
    • Farlo funzionare e testarlo adeguatamente
    • Da ESP32: connettersi alla rete Wifi
    • Da ESP32, realizzare un semplice circuito con un sensore di input
    • Da ESP32, inviare tramite la libreria requests il dato al server Flask
    • Da ovunque, con un browser... visualizzare il dato ricevuto

    Fatto questo... lavoriamo su ESP32:

    • Da ESP32, realizzare un semplice sito con microdot
    • Farlo funzionare e testarlo adeguatamente
    • Connettersi al sito per modificare lo stato di un sensore di output

    Mettendo insieme questo e quello:

    • Da ESP32, realizzare un semplice sito con microdot
    • Dal PC, realizzare un semplice sito in Flask per inviare richieste a ESP32
    • Dal sito sul PC clicco... su ESP32 si accende un led.

    Poi sparecchio e vado a casa soddisfatto. Iniziamo!!!

    ESP32: connessione al wifi

    Fai così... immagina di volerti connettere alla rete wifi chiamata "PIPPO" (quello in informatica sarebbe l'ESSID della rete wifi) che ha password "PAPERINO" (in realtà si chiama key oppure passphrase). Allora tu fai così:

    import network
import time

# l'opzione network.STA_IF crea una interfaccia in grado di connettersi ad una rete Wifi
wlan = network.WLAN(network.STA_IF)

# attiva l'interfaccia
wlan.active(True)

# connette l'interfaccia WLAN alla rete Wifi PIPPO con chiave PAPERINO
wlan.connect('PIPPO', 'PAPERINO')

while not wlan.isconnected():
    print("waiting for connection...")
    time.sleep(1)

print("Connected!")
print(wlan.ifconfig())

    Tutto qui! Ricorda al prof che deve attivare un'altra rete, perché con la rete WifiDaVinci l'ESP32 non funziona!!! Quello sarebbe un altro dei problemi capitati la scorsa volta...

    ESP32 urequests

    Quello che vogliamo fare adesso è inviare richieste GET e non tramite una pagina web, ma tramite una piccola applicazione (Micro)Python in esecuzione sull'ESP32.

    La libreria urequests è la libreria MicroPython standard per l'invio dati tramite HTTP. Vediamo un esempio banale di richiesta GET. Tutto il contorno dovrete inserirlo voi...

    richiesta GET
    import requests

# immagina di voler inviare la temperatura di 27.5°C
temperatura = 27.5

IP_DEL_PC = "192.168.110.102" # Ad esempio...

URL_di_INVIO = f"http://{IP_DEL_PC}:5000/ascolta/" + str(temperatura)

# visualizza l'URL di invio per capire cosa stai facendo...
print("URL:", URL_di_INVIO)

# poi invia tutto!
resp = requests.get(URL_di_INVIO)
print('Response content:', resp.text)
# Al server in ascolto (si spera) su IP_DEL_PC arriverà il dato 27.5

    server ESP32: Flask --> ESP32

    Ho provato ogni microserver disponibile in rete... ma per essere sicuri (abbastanza sicuri...) che funzioni, l'unica è scrivere le cose a manina...

    Il codice non è semplicissimo, ma alcune parti si capiscono bene. Provate e vedete!

    # ... prima carichi la connessione di rete... 

# poi configuri il tuo led...
from machine import Pin

print("setting LED...")
led = Pin(15, Pin.OUT)
led.off()

# infine cominci con la libreria socket
import socket

s = socket.socket()
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
s.bind(("0.0.0.0", 80))
s.listen(1)
print("In ascolto sulla porta 80")
stato = "SPENTO"

while True:
    client, indirizzo = s.accept()          # si blocca finche' arriva una richiesta
    richiesta = client.recv(1024).decode()
    if not richiesta:
        client.close()
        continue

    # La prima riga della richiesta e' tipo:  GET /led/1 HTTP/1.1
    prima_riga = richiesta.split("\r\n")[0]
    percorso = prima_riga.split(" ")[1]
    print(indirizzo[0], "->", percorso)

    if percorso == "/led/1":
        print("VALUE 1")
        led.on()
        stato = "ACCESO"
    elif percorso == "/led/0":
        print("VALUE 0")
        led.off()
        stato = "SPENTO"

    pagina = (
        "<h1>ESP32</h1>"
        "<p>LED: " + stato + "</p>"
        '<a href="/led/1">ON</a> | <a href="/led/0">OFF</a>'
    )

    # Risposta HTTP: riga di stato, intestazione, riga vuota, corpo
    risposta = "HTTP/1.0 200 OK\r\nContent-Type: text/html\r\n\r\n" + pagina
    client.send(risposta.encode())
    client.close()
